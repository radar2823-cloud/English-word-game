# English Quest

GitHub Pages에서 실행하는 12시간 단위 영어 상황 미션 게임입니다.

- 선택형 2문제 + 새로운 표현의 문장 조립 1문제
- 각 미션의 세 정답 문장은 서로 다르며, 미국 일상 회화에서 자연스러운 표현을 기준으로 구성
- 50개 상황 미션을 중복 없이 순환 (한 바퀴 25일)
- 한국 시간 기준 오전 0시·낮 12시에 다음 미션으로 변경. 같은 시간대에는 모든 플레이어가 같은 미션을 받음
- 결과 공유 기능 (모바일 공유 메뉴 또는 클립보드 복사)
- 브라우저에 연속 완료, 최고 연속 기록, 완료 미션 수, 평균 점수와 최근 기록 저장 및 조회
- 연승 칭호: 5연승 `영단어 고수` · 10연승 `토익 900 동급` · 30연승 `영주권 발급` · 50연승 `원어민 ㅇㅈ`

## GitHub Pages 배포

1. 이 폴더를 새 GitHub 저장소에 올립니다.
2. 저장소의 **Settings → Pages**에서 `Deploy from a branch`를 선택합니다.
3. `main` 브랜치와 `/ (root)` 폴더를 선택해 저장합니다.
4. 안내되는 Pages 주소를 친구에게 공유합니다.

정적 HTML/CSS/JavaScript만 사용하므로 별도 서버나 설치 과정이 필요 없습니다.
기록은 브라우저의 `localStorage`에 저장되므로 같은 브라우저에서 유지되며, 기기나 브라우저가 바뀌면 공유되지 않습니다.
