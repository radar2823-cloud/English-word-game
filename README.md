# 영단어 5

하루에 한 번 바뀌는 5글자 영어 단어 게임입니다. 브라우저에서만 동작하는 정적 파일이라 GitHub Pages에 올리면 친구들이 링크로 바로 플레이할 수 있습니다.

## 파일 구성

- `index.html`: 게임 전체 파일입니다.
- `README.md`: 업로드와 운영 안내서입니다.

## GitHub Pages에 올리는 방법

1. GitHub에 로그인합니다.
2. 오른쪽 위 `+` 버튼을 누르고 `New repository`를 선택합니다.
3. 저장소 이름을 입력합니다. 예: `word-5`
4. `Public`을 선택합니다.
5. `Create repository`를 누릅니다.
6. 새 저장소 화면에서 `uploading an existing file` 또는 `Add file` > `Upload files`를 누릅니다.
7. 이 폴더의 `index.html`과 `README.md`를 끌어다 놓습니다.
8. 아래쪽 `Commit changes`를 누릅니다.
9. 저장소 상단 메뉴에서 `Settings`로 갑니다.
10. 왼쪽 메뉴에서 `Pages`를 선택합니다.
11. `Build and deployment`의 `Source`를 `Deploy from a branch`로 둡니다.
12. `Branch`를 `main`, 폴더를 `/root`로 선택한 뒤 `Save`를 누릅니다.
13. 1-5분 정도 기다리면 같은 화면에 접속 주소가 표시됩니다.

주소는 보통 아래 형태입니다.

```text
https://깃허브아이디.github.io/저장소이름/
```

예를 들어 GitHub 아이디가 `minji`이고 저장소 이름이 `word-5`라면 주소는 아래처럼 됩니다.

```text
https://minji.github.io/word-5/
```

이 링크를 카카오톡으로 친구들에게 보내면 됩니다.

## 정답이 바뀌는 방식

게임은 한국 시간 기준으로 하루에 한 번 정답이 바뀝니다. 같은 날 같은 링크에 접속한 친구들은 모두 같은 정답을 풉니다.

정답 선택은 `index.html` 안의 `ANSWERS` 목록, 오늘 날짜, `DAILY_RANDOM_SEED` 값을 섞어서 자동 계산됩니다. 목록 위에서 아래로 순서대로 나오지 않고, 날짜마다 랜덤처럼 고정된 정답이 선택됩니다.

`DAILY_RANDOM_SEED` 값을 바꾸면 날짜별 정답 흐름이 전체적으로 바뀝니다. 이미 친구들과 운영 중이라면 seed는 그대로 두는 것을 추천합니다.

## 단어 목록 수정 방법

1. GitHub 저장소에서 `index.html`을 엽니다.
2. 오른쪽 위 연필 아이콘을 눌러 편집합니다.
3. 아래 코드를 찾습니다.

```js
const ANSWERS = [
```

4. 정답으로 낼 단어를 추가하거나 삭제합니다.
5. 정답 단어의 뜻과 예문은 아래 코드를 찾아 `WORD_NOTES` 목록에 넣습니다.

```js
const WORD_NOTES = {
```

6. 제출만 허용하고 정답으로는 내지 않을 단어는 아래 코드를 찾아 `EXTRA_GUESSES` 목록에 넣습니다.

```js
const EXTRA_GUESSES = [
```

주의할 점:

- 단어는 영어 알파벳 5글자여야 합니다.
- 소문자로 넣어도 게임 안에서는 대문자로 처리됩니다.
- 현재 구성은 정답 후보 `ANSWERS` 약 700개, 입력 허용 전용 `EXTRA_GUESSES` 약 3,000개입니다.
- `ANSWERS`에 단어를 추가하거나 삭제하면 일부 날짜의 정답이 바뀔 수 있습니다.
- `WORD_NOTES`에 뜻과 예문을 넣으면 정답 공개 후 단어 노트에 표시됩니다.
- 뜻과 예문을 아직 넣지 않은 단어가 정답이어도 게임은 정상 동작하고, 미등록 안내가 표시됩니다.
- 친구들이 자주 입력할 만한 단어가 거절되면 `EXTRA_GUESSES`에 추가하면 됩니다.

## GitHub에 수정본 다시 올리는 방법

기존 GitHub Pages 저장소의 `index.html`을 삭제한 뒤 다시 업로드해도 됩니다. 더 간단하게는 GitHub에서 기존 `index.html`을 열고 연필 아이콘으로 편집한 다음, 이 폴더의 `index.html` 전체 내용을 붙여넣고 `Commit changes`를 누르면 됩니다.

`README.md` 안내도 같이 바꾸고 싶다면 같은 방식으로 `README.md`도 교체하면 됩니다.

## 로컬에서 확인하는 방법

이 폴더의 `index.html`을 브라우저로 열면 바로 실행됩니다. 별도 설치나 서버 실행이 필요 없습니다.

## 친구들이 사용하는 방법

1. GitHub Pages 주소를 엽니다.
2. 화면 키보드나 실제 키보드로 5글자 영어 단어를 입력합니다.
3. `입력`을 누릅니다.
4. 초록색, 노란색, 회색 힌트를 보고 최대 5번 안에 맞춥니다.
5. 정답이 공개되면 뜻과 예문을 확인합니다.
6. 완료 후 `결과 공유`를 눌러 결과를 복사하거나 공유합니다.
